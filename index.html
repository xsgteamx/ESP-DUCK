连接方式

USB 模式通过 Web Serial 连接开发板 UART 口；Wi-Fi 模式通过开发板 IP 调用接口。

USB 串口模式

A 电脑连接开发板 UART 口，浏览器通过串口发送文本和设置；开发板另一个 USB 口接 B 设备，作为 HID 键盘输出。

未连接
使用前请关闭 Arduino IDE 串口监视器。连接时选择开发板 UART 口对应的 COM 口。

Wi-Fi 局域网模式

输入开发板 IP 后，可以通过 HTTP 接口访问开发板。公网 HTTPS 页面直连局域网 HTTP 可能被浏览器拦截；这种情况请直接打开开发板网页。

保活模式

开启后开发板会按指定动作保活。正在发送文本时会暂停保活。

默认保活动作为“鼠标点击 + F5”。复杂动作会影响当前窗口，适合需要刷新页面/界面的场景，测试前请确认光标和窗口位置。
